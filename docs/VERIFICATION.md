## 分发目录检查

源文件按白名单纳入，没有复制数据库／WAL／会话、用户照片／文章、密码哈希、备份、云登录缓存、令牌、部署补丁、嵌入部署载荷、历史发布包、截图或日志。文本检查包括部署者标识、个人路径、IP、UUID、邮箱／URL、私钥、常见令牌格式、scrypt 哈希与长编码载荷；二进制资源检查包括 GLB JSON 元数据、Ogg 注释、字体名称表与许可 PDF。没有检出原站点的个人配置或真实凭据。合法作者／厂商署名及许可证内的联系信息保留。

唯一测试 JPEG 是新生成的纯色图，没有 EXIF；合成测试档案由测试模块按需生成，不会导入运行站点。所有可用测试密码在运行时随机生成。测试数据库、安装依赖、dist、release 及核查工具缓存在交付前移除。

`SOURCE_MANIFEST.json` 记录交付文件相对路径、大小与 SHA-256（不含清单自身），便于复核白名单。必要大文件是四个 MiSans 字体和两个 GLB；最大单文件约 4.85 MiB，没有历史包或超大视频。对已复制的原始源文件再次校验，未发生变更。
