# 栏目配置

`site.json` 的 `columns` 是五列内部分类，顺序对应界面；`categories` 是同一组五个唯一分类，用于检索。`column-labels.json` 是按列顺序显示的五个中文栏目名，默认主页、归档、画廊、随笔、关于。

优先只改显示名。后端与前端目前按第三列（索引 2）判断画廊，修改显示名不会改变这个规则。不要通过调换分类顺序移动已有照片档案。

内部分类已经保存进数据库文章的 `category` 字段。空库时可一并修改两个配置数组并保持五项；有数据后重命名内部分类需要专门的数据迁移，不能只改 JSON。配置不存文章内容，程序也不会导入 `server/fixtures`。

修改配置后执行 `npm run check`、`npm run build`，部署时同时更新 `content/` 和 `dist/` 并重启后端。只重建前端或只替换 JSON 会造成前后端分类不一致。
